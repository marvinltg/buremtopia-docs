Growtopia Private Server — Technical Reference

Welcome to GTPS3 Docs

Complete technical documentation for the GTPS3 Growtopia Private Server

Quick Start

GTPS3 is a C++/Node.js Growtopia private server implementation featuring:

  • ENet-based game server — UDP networking with reliability, sequencing, fragmentation
  • HTTPS Resolver (Node.js) — Local server_data.php & login webview on port 443
  • Custom packet protocol — Variant-based serialization (gamepacket_t)
  • JSON data persistence — Players, worlds, guilds stored as flat files
  • Web login dashboard — Modern UI served via HTTPS resolver

Core Systems

ENet Networking

UDP networking library providing reliable/unordered delivery, peer management, bandwidth throttling, and packet fragmentation.

Packet Protocol

Custom variant-based serialization (gamepacket_t) with typed insertion (string, int, uint, float, vec2, vec3) and ENet packet creation.

HTTP/HTTPS Resolver

The client resolves server_data.php via HTTPS (port 443) to get the ENet server IP/port, then connects via ENet UDP. The Node.js HTTPS server also serves the login webview and static game assets.

Requirements

Build

  • Visual Studio 2022 (MSVC v143)
  • Windows 10/11 x64
  • Node.js 18+ (for HTTPS resolver)

Runtime (Admin required)

  • Port 80 (C++ HTTP resolver fallback)
  • Port 443 (Node.js HTTPS resolver)
  • Port 53181 (ENet game server)
  • Port 8080 (HTTP debug)

Client Setup

  • Hosts file entries for growtopia1/2.com
  • Trust resolver.pfx cert (LocalMachine\Root)
  • Growtopia client 5.4x/5.5x
